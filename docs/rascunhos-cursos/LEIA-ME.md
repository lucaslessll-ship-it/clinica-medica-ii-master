# Materiais e primeiro lote textual

## Entregue neste lote

- `pocus-m4-m6.lesson-deep.js`: textos autorais de pulmão e pleura, FAST e E-FAST, avaliação cardíaca focada e cava. Cada módulo contém 6 pré-testes, 4 itens de prova, fluxo, raciocínio, 3 mnemônicos, erros, 8 evocações, prática e referências. As chaves seguem o padrão tema e índice: `pocus_m4_0`, `pocus_m5_0` e `pocus_m6_0`.
- `hemograma-mapa-20-modulos.json`: correspondência dos 20 capítulos do guia com títulos temáticos para o curso. Os textos desses módulos ainda estão pendentes.

O arquivo JavaScript exporta dados para revisão. A integração ao curso e às rotas do site ainda precisa ser feita. Nenhuma imagem, marcação ou registro do Supabase foi alterado. Estes arquivos foram salvos como rascunhos editoriais no repositório. A aplicação dos textos ao curso permanece pendente de revisão; os PDFs originais não foram incluídos.

Sintaxe JavaScript e mínimos estruturais dos três módulos foram verificados. Isso não equivale a testes de interface ou validação médica das recomendações atuais.
