# Cobertura do manual de prescrição

54 aulas, 16 matérias e 16 fichas selecionadas com 16 exemplos de cálculo. **Não é um formulário completo de todos os tratamentos.**

O roteiro abaixo vem das aulas reais. As referências de uma matéria não constituem indicação para todas as doenças da matéria. O detalhamento de novos regimes depende de consulta a diretrizes/bulas e conferência por indicação. Nesta sessão, as três fontes oficiais acima responderam com bloqueio de proxy 403. Nenhuma dose nova foi gerada a partir deste inventário.
